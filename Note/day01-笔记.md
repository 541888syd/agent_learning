## 2. print() — 在屏幕上显示东西

```python
print("Hello")      # 显示文字，必须加引号
print("你好世界")
print(123)          # 显示数字，不需要引号
```

---

## 3. 变量 — 有名字的盒子

```python
name = "小明"       # 把"小明"放进name这个盒子
age = 25            # 把25放进age这个盒子
print(name)         # 拿出name盒子里的东西 → 小明
```

- `=` 不是等于号，是「**把右边的东西放进左边**」
- 变量名随便起，但不能用数字开头

---

## 4. input() — 停下来等用户打字

```python
name = input("你叫什么？")    # 屏幕显示"你叫什么？"，等用户输入
```

- 程序会暂停，等用户输入
- 用户输入的内容会被存进变量

---

## 5. f-string — 把变量塞进文字里

```python
name = "小明"
age = 25
print(f"你好{name}，你{age}岁")   # → 你好小明，你25岁
```

- `f` 写在引号前面
- `{变量名}` 会被替换成变量的值

---

## 6. 变量类型（重点！）

| 类型 | 写法 | 例子 | 说明 |
|------|------|------|------|
| 字符串 `str` | 加引号 | `"hello"` | 文字，不能算数 |
| 整数 `int` | 不加引号 | `25` | 整数，能算数 |
| 浮点数 `float` | 小数点 | `3.14` | 小数，能算数 |
| 布尔 `bool` | 大写 | `True` `False` | 只有真和假 |

---

## 7. 最重要的坑：input() 永远返回字符串！

```python
age = input("年龄：")    # 你输入 25，但 age 是 "25"（文字）
print(age + 1)           # 💥 报错！文字不能加数字
```

**解决方法**：用 `int()` 转成数字

```python
age = int(input("年龄："))   # 现在 age 是数字 25
print(age + 1)               # ✅ 26
```

---

## 8. 类型转换三兄弟

| 函数 | 作用 | 例子 |
|------|------|------|
| `int(x)` | 转整数 | `int("25")` → `25` |
| `float(x)` | 转小数 | `float("3.14")` → `3.14` |
| `str(x)` | 转文字 | `str(25)` → `"25"` |
| `type(x)` | 查看类型 | `type(25)` → `<class 'int'>` |
