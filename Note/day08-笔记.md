## 一、`str.split()` — 字符串切割

| 项目 | 内容 |
|------|------|
| **所属库** | 内置（不需要 import） |
| **类型属性** | 字符串操作方法 |
| **名字来源** | **split** = 劈开、切开 |
| **功能描述** | 按分隔符把字符串切成多个片段，返回列表 |
| **函数签名** | `str.split(sep=None, maxsplit=-1)` |
| **参数列表** | `sep` — 分隔符，不传按任意空白切；`maxsplit` — 最多切几次（-1=不限） |
| **返回值** | `list` — 切割后的片段列表 |

```python
"苹果,香蕉,橘子".split(",")       # ['苹果', '香蕉', '橘子']
"a b c".split()                    # 不传 → ['a', 'b', 'c']
"a,b,c".split(",", 1)              # 只切一次 → ['a', 'b,c']
```

## 二、`str.join()` — 字符串拼接

| 项目 | 内容 |
|------|------|
| **所属库** | 内置（不需要 import） |
| **类型属性** | 字符串操作方法 |
| **名字来源** | **join** = 连接、汇合 |
| **功能描述** | 用分隔符把列表里的字符串拼成一个大字符串 |
| **函数签名** | `str.join(iterable)` |
| **参数列表** | `iterable` — 可遍历对象，**里面必须全是字符串** |
| **返回值** | `str` — 拼接后的字符串 |

```python
",".join(["苹果", "香蕉"])        # "苹果,香蕉"
" ".join(["hello", "world"])      # "hello world"
"".join(["1", "9", "2"])          # "192"
".".join(["192", "168", "1"])    # "192.168.1"
```

⚠️ 写法注意：`分隔符.join(列表)`，不是 `列表.join(分隔符)`。

## 三、`str.strip()` — 剥掉首尾

| 项目 | 内容 |
|------|------|
| **所属库** | 内置（不需要 import） |
| **类型属性** | 字符串操作方法 |
| **名字来源** | **strip** = 剥掉、脱去（像剥香蕉皮） |
| **功能描述** | 去掉字符串首尾的指定字符 |
| **函数签名** | `str.strip(chars=None)` |
| **参数列表** | `chars` — 要去掉的字符集合，不传去空格/换行/制表符 |
| **返回值** | `str` — 去掉首尾后的新字符串 |

```python
"   你好   ".strip()              # "你好"
"***标题***".strip("*")           # "标题"
"\nhello\n".strip()               # "hello"
"  he llo  ".strip()              # "he llo"（中间空格不动）
```

## 四、`str.replace()` — 替换

| 项目 | 内容 |
|------|------|
| **所属库** | 内置（不需要 import） |
| **类型属性** | 字符串操作方法 |
| **名字来源** | **re** + **place** = 重新放置 → 替换 |
| **功能描述** | 把字符串中的旧内容替换成新内容 |
| **函数签名** | `str.replace(old, new, count=-1)` |
| **参数列表** | `old` — 被换掉的；`new` — 换成这个；`count` — 最多换几次（-1=全换） |
| **返回值** | `str` — 替换后的新字符串 |

```python
"hello world".replace("world", "Python")   # "hello Python"
"a,b,c".replace(",", " | ")                # "a | b | c"
"张张张".replace("张", "李", 2)           # "李李张"
```

## 五、`re` 模块 — 正则表达式

| 项目 | 内容 |
|------|------|
| **所属库** | `re` 模块（需要 `import re`） |
| **类型属性** | 正则表达式匹配模块 |
| **名字来源** | **re** = **R**egular **E**xpression = 正则表达式 |

### 5.1 常用符号

| 符号 | 全称 | 意思 |
|:---:|------|------|
| `\d` | **d**igit | 一个数字 0-9 |
| `\d+` | digit + | 一个或多个数字 |
| `\w` | **w**ord character | 一个字母/数字/下划线 |
| `\w+` | word character + | 一个或多个字母/数字/下划线 |
| `\s` | **s**pace | 一个空白符（空格/换行/制表符） |
| `.` | — | 任意一个字符 |
| `\.` | — | 真正的点号（反斜杠转义） |
| `+` | — | 前面出现 1 次或多次 |
| `*` | — | 前面出现 0 次或多次 |

### 5.2 `re.findall()` — 找出所有匹配

| 项目 | 内容 |
|------|------|
| **所属库** | `re` 模块 |
| **类型属性** | 正则匹配方法 |
| **名字来源** | **find** + **all** = 找出所有 |
| **函数签名** | `re.findall(pattern, string, flags=0)` |
| **参数列表** | `pattern` — 正则表达式；`string` — 搜索文本；`flags` — 可选标志 |
| **返回值** | `list` — 所有匹配到的字符串列表，无匹配返回 `[]` |

```python
import re

# 抓所有数字块
re.findall(r"\d+", "IP: 192.168.1.1")
# → ['192', '168', '1', '1']

# 抓 IP 地址（四组数字用点连）
re.findall(r"\d+\.\d+\.\d+\.\d+", "访问: 192.168.1.1 和 10.0.0.5")
# → ['192.168.1.1', '10.0.0.5']
```

### 5.3 `re.search()` — 找第一个匹配

```python
import re
match = re.search(r"\d+", "abc123def456")
print(match.group())    # '123'  ← 第一个
```

### 5.4 `re.sub()` — 找到并替换

```python
import re
re.sub(r"\d+", "X", "电话138, 邮编100000")
# → '电话X, 邮编X'
```

## 六、日志解析器（主线任务）

```python
import re

log = """2024-01-01 10:30:45 192.168.1.1 GET /index.html
2024-01-01 10:31:12 10.0.0.5 POST /login
2024-01-01 10:32:01 192.168.1.1 GET /about
2024-01-01 10:33:45 172.16.0.8 GET /contact"""

# 逐行解析
for line in log.split("\n"):
    parts = line.split(" ")
    print(f"时间: {parts[0]} {parts[1]}, IP: {parts[2]}")

# 正则抓全部 IP
ips = re.findall(r"\d+\.\d+\.\d+\.\d+", log)
print(f"所有IP: {ips}")
```

步骤拆解：
1. `log.split("\n")` → 拆成一列行
2. 每行 `.split(" ")` → 拆成字段列表
3. `parts[0]` 日期 + `parts[1]` 时间 + `parts[2]` IP
4. 正则一把抓出所有 IP

## 七、正则 `+` vs `*`

| | `+` | `*` |
|---|-----|-----|
| 最少出现次数 | 1 次 | 0 次 |
| `\d+` 对 `"abc"` | `[]` 不匹配 | `['']` |
| 实用度 | 日常主力 | 偶尔用 |
